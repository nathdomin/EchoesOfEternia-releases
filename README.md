# Echoes of Eternia

MMORPG em pixel art feito em Godot 4. Tem servidor dedicado, contas, personagens salvos e até 16 jogadores.

Este repositório guarda **só os downloads do jogo**. O código-fonte é aberto (licença MIT) e está em [nathdomin/EchoesOfEternia](https://github.com/nathdomin/EchoesOfEternia).

## Como jogar

1. Abra a [última versão](../../releases/latest) e baixe o **EchoesOfEternia-cliente.zip**.
2. Descompacte numa pasta sua (por exemplo, Documentos ou Área de Trabalho) e abra o **EchoesOfEternia.exe**.
   - Se aparecer "O Windows protegeu o computador", clique em **Mais informações → Executar assim mesmo**. O jogo não tem assinatura digital.
3. No menu, clique em **Criar conta**. O servidor já vem preenchido:

   | Servidor | Porta |
   |---|---|
   | `152.67.51.151` | `7777` |

   Se o campo estiver com outro endereço, digite estes.

O arquivo `COMO_JOGAR.txt`, dentro do zip, explica os controles e o chat. No jogo, o F1 mostra a ajuda.

## Atualizações

Você só baixa o zip uma vez. Ao abrir, o jogo confere se há versão nova, baixa, instala e reabre sozinho.

Se a pasta do jogo não deixar gravar (por exemplo, `Arquivos de Programas`), o menu avisa, e aí basta baixar a última versão aqui.
